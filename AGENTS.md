# Profit Planet Operating Rules

- Keep Profit Planet mobile-first, polished, and easy to understand.
- Preserve the shared marketplace and existing working game flows unless an approved outcome explicitly changes them.
- Test code changes with typecheck, lint, the relevant money audit, production build, and rendered browser checks for changed journeys.
- Commit to `main`, push to `AWD1436-okad/Bazaarly`, and verify the existing Vercel production deployment before reporting completion.
- Never spend real money, create paid services, expose secrets, or delete production data without an explicit owner approval for that occurrence.
- Treat virtual-balance, stock, subscription, and checkout changes as transactional business-logic work: validate server-side, preserve existing data, and avoid duplicate charges or purchases.
